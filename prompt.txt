PROJECT: MAYA PICTURES
PROJECT TYPE: Professional Photography Studio Website + Content Management System
IMPLEMENTATION MODE: Production-ready full-stack application
VISUAL BASELINE: Existing landing.html prototype supplied in the project
DESIGN TOOL: Do NOT use Stitch. Use landing.html directly as the visual/design baseline.

============================================================
1. PRIMARY OBJECTIVE
============================================================

Build the complete Maya Pictures photography website and management system.

The existing landing.html file is the visual prototype and must be treated as the primary visual reference.

Do NOT discard the existing visual identity and redesign the website from scratch.

Instead:

1. Study landing.html carefully.
2. Preserve its strongest visual characteristics.
3. Convert its static/mockup concepts into a proper production architecture.
4. Expand the website so that every required public page and every required administrative/CMS page exists.
5. Make all business/content information manageable from the admin dashboard.
6. Ensure the public website is fully responsive.
7. Ensure the system is secure, maintainable, scalable and production-ready.
8. Do not omit functionality simply because it was not represented in landing.html.
9. Do not implement future modules such as full CRM, invoicing or client portal unless explicitly marked as future-ready architecture.
10. The current release is:
   PUBLIC WEBSITE + CMS + MEDIA MANAGEMENT + INQUIRY/BOOKING REQUEST MANAGEMENT.

The SRS/master documentation is the functional baseline.
The landing.html file is the visual baseline.

When the two differ:
- use landing.html for visual direction
- use the SRS for required functionality
- do not remove an SRS requirement merely because it is absent from landing.html.

2. BRAND IDENTITY
============================================================

Brand name:

MAYA PICTURES

Use "Maya Pictures" consistently.

Do not use placeholder names such as:
- Lenscraft
- Maya VIP Studio
- New York studio
- any unrelated photography-company identity

unless they are explicitly part of existing prototype text that must be replaced.

The visual identity must remain premium, editorial, cinematic, elegant, minimal and photography-first.

PRIMARY BRAND ACCENT:

Burgundy / wine-red.

Reference color from landing.html:

--burgundy-light: #8f2a3e
--burgundy-pale: #f4e8ea

Use this color selectively.

DO NOT make the entire website burgundy.

Supporting palette:

- warm cream
- ivory
- off-white
- charcoal
- near-black
- subtle neutral grays
- restrained gold/tan accent only where visually appropriate

Existing prototype also contains:

--gold-accent: #b8865a
--bg-cream: #fcf9f6
--text-dark: #1e1a1c

Preserve this general visual relationship.

The photography must dominate the interface.

Avoid:

- excessive animations
- excessive glassmorphism
- generic SaaS dashboards on the public site
- excessive rounded cards
- visual clutter
- excessive decorative elements
